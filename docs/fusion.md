# 融合

`core/fusion.ts` 的 `fuse(head, body, nbPokemon)`，照 `Data/Scripts/052_InfiniteFusion/Fusion/Data/FusedSpecies.rb` 移植。

## 規則

| 項目 | 規則 |
| --- | --- |
| 能力值 | `floor(2 × 主導方 / 3) + floor(另一方 / 3)`；頭主導 HP、特攻、特防，身體主導攻擊、防禦、速度 |
| 第一屬性 | 頭的第一屬性；頭是一般/飛行時取飛行 |
| 第二屬性 | 身體的第二屬性；跟第一屬性相同時改取身體的第一屬性（身體單屬性時，第二屬性就是第一屬性） |
| 一般特性欄 | [身體第一特性, 頭第一特性] |
| 隱藏特性欄 | [身體第二特性, 頭第二特性, 身體隱藏特性, 頭隱藏特性]；沒有第二特性時用第一特性，沒有隱藏特性時用同一方的第二特性 |
| 可選特性 | 一般欄 + 隱藏欄（`Pokemon#getAbilityList`），等於兩隻原本的所有特性 |
| 招式 | 身體與頭的升級、教學、蛋招清單直接合併（身體在前） |
| 代號、編號 | `B<身體編號>H<頭編號>`；身體編號 × NB_POKEMON + 頭編號 |
| 戰鬥切換 | 出攻擊招時直接對調當下的攻擊↔防禦、特攻↔特防（`stanceChangeSwap`），不是換形態重算種族值 |

## 已知事項

- **南瓜精、南瓜怪**：種族值依尺寸而定（`Pokemon#getBaseStatsFormException`），目前只用普通尺寸，指令會提示
- **進化前的招式**：融合的可學招式只有兩隻本身的清單。進化前才學得到的招式要不要算，需要先確認遊戲的招式回憶機制（未確認）
- **融合名稱**：遊戲用 `SPLIT_NAMES` 拼接名稱，目前顯示成「頭 / 身體」

## 指令

```bash
pnpm fuse 堅盾劍怪 大鋼蛇            # 先頭後身體：屬性、種族值、特性、可學招式數
pnpm calc 瑪力露麗/請假王 --level 50  # 融合的攻擊招式依傷害排序
```
