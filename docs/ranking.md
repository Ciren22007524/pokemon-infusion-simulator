# 攻擊力排行

`pnpm rank`：對全部 576 × 576 種「頭 × 身體」擺法（含兩種擺法與自體融合）計算，依下面的標準排序。完整結果寫到 `output/ranking.csv`（不進 repo）。

核心在 `core/ranking.ts`，命中率在 `core/accuracy.ts`。

## 排名標準

**主標準：每回合期望傷害**，取該融合「可選特性 × 可學攻擊招式」中的最大值。

```
每回合期望傷害 = 每下平均傷害 × 命中率 × 期望下數 × 每回合倍率
```

| 項目 | 定義 |
| --- | --- |
| 每下平均傷害 | 對參考對象的傷害，亂數 85～100 共 16 個值的平均（`DamageCalculator`） |
| 命中率 | 照 `pbAccuracyCheck`，含複眼、活力、無防守、純樸；必中招為 100% |
| 期望下數 | 一般 1 下；固定 2 下的招式 2；2～5 下的招式 19/6（連續攻擊 5）；三連踢見下方 |
| 每回合倍率 | 需要休息（破壞光線類）、蓄力招、懶惰：×0.5；其他 ×1 |

**第二標準**：速度（融合後的種族值）高的在前；再相同時比 HP。

擊中要害（基本機率 1/24）不計入。

## 參考條件

- 等級 50、個體值 31、努力值 0、個性無修正（可用 `--level` 改等級）
- 防守方：沒有屬性、防禦 = 特防 = 100、沒有特性與道具（見 `docs/damage.md`）
- 單打、沒有天氣與場地、雙方滿 HP、沒有異常狀態與能力變化
- 攻擊方沒帶道具、親密度 255
- 這回合先攻、招式第一次使用、剛上場（慢啟動生效中）

## 招式的特殊算法

每個改寫了傷害、命中、次數或失敗條件的效果代碼，都對照原始碼檢查過在參考條件下的結果，規則在 `core/ranking.ts` 的 `REFERENCE_MOVE_RULES`：

| 類型 | 例子 |
| --- | --- |
| 和一般算法相同 | 地震（只在對方挖洞時加倍）、噴火（滿 HP 時 150）、日光束（沒有天氣時不減半） |
| 算出確定值 | 報恩 102、捏碎 120、雜技 ×2（沒帶道具）、山嵐摔必定擊中要害、燕返必中、地球上投 = 等級 |
| 排除 | 依對方而定（踢倒、陀螺球、欺詐）、隨機（禮物、震級）、一擊必殺、自己倒下（大爆炸）、條件不成立（真氣拳、擊掌奇襲、食夢） |

沒有規則、又改寫了這些方法的招式一律排除，不會用一般算法硬算。目前 440 招攻擊招式中排除 46 招。

三連踢：威力依序 10、20、30，每一下都判定命中，沒中就停止；有連續攻擊時只判定第一下。

## 額外欄位（不影響排名）

- 備註：需休息、蓄力、鎖招（逆鱗類）、反作用、自損、懶惰、種族值依尺寸（南瓜精、南瓜怪）、自體融合

## 已知限制

- 只看單一最強招式，不看屬性覆蓋
- 防守能力（HP、防禦、特防）不影響排名
- 連斬、滾動等連續使用會變強的招式只算第一次
- 進化前才學得到的招式不在可學清單內
- 道具、雙打、天氣隊等搭配沒有計算
- 還沒有「是否神獸」「是否野生可得」欄位
