# 決定

| 日期 | 決定 | 原因 |
| --- | --- | --- |
| 2026-10-29 | 技術：TypeScript 計算核心，之後用 Tauri + Vue 3 + Quasar 做桌面版 | 使用者熟 Vue / Quasar；Tauri 可同時產出 Windows 與 Mac 版 |
| 2026-10-29 | 資料分兩層：`data/raw`（原樣）與正規化資料表 | 原樣資料可追查與 diff，正規化資料表方便查詢 |
| 2026-10-29 | 用自寫的純資料解析器讀遊戲 `.dat`，不用 Ruby `Marshal.load` | `Marshal.load` 讀外來檔案有執行程式碼的風險；也省去安裝 Ruby |
| 2026-10-30 | 傷害計算照原始碼逐段移植，不用 `@smogon/calc` | 本傳公式與 IF 不同（擊中要害倍率、四捨五入時機、戰鬥切換） |
| 2026-10-30 | 排行用不指定防守方的傷害（參考對象：無屬性、防禦 = 特防 = 100） | 只比較攻擊方的能力值、特性、招式三者的組合 |
| 2026-10-30 | 排行要把命中率算進去 | 使用者決定 |
| 2026-10-30 | 分支用 `feature-xxx`，PR 合併回 `main` | 使用者決定 |
| 2026-10-30 | 排行主標準：每回合期望傷害（平均傷害 × 命中率 × 期望下數；需休息、蓄力、懶惰 ×0.5）；第二標準：速度 | 類似 DPS；休息與蓄力兩回合才打一次。第二標準是暫定，可再調整 |
| 2026-10-30 | 排行排除使用後自己倒下、依對方而定、隨機、條件不成立的招式；擊中要害不計入 | 參考條件下無法得到確定值；排除比用一般算法硬算可靠 |
